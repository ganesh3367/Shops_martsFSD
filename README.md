# 🪑 Furniture Shop Website

A modern and responsive **Furniture Shop Website** built using **HTML, CSS, and JavaScript**.
This project showcases different furniture products with an attractive UI and smooth user experience.

---

## 🚀 Features

* 🛋️ Modern UI design
* 📱 Fully responsive layout
* 🧭 Easy navigation
* 🛒 Product showcase section
* 📩 Contact section
* ⚡ Fast loading

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
